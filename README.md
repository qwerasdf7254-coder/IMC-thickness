# IMC 두께 측정 도구 (SEM 단면 이미지, 정답 라벨 없음)

솔더 접합부(solder) - 금속간화합물층(IMC, Cu6Sn5) - 구리 전극(Cu) 계면의 SEM BSE(COMPO) 단면
이미지에서 IMC 층 두께를 자동/반자동으로 측정하는 CLI 도구.

## 왜 이런 방식인가

측정 대상 데이터에는 두께 정답값이 없다. 따라서 "정답에 맞춰 학습"하는 지도학습 대신,
**이미지 자체의 통계(밝기/텍스처 히스토그램, 국소 분산)에서 매 이미지마다 경계 기준을
다시 계산**하는 방식을 택했다. 라벨이 없어도 바로 쓸 수 있고, 왜 그 경계를 골랐는지
오버레이 이미지로 항상 확인할 수 있다.

## 알고리즘 (2단계)

1. **Cu/IMC 경계 (신뢰 가능 단계)**
   Cu 패드는 연마되어 매끈하고, 그 위 IMC 스캘럽 층은 결정립계가 촘촘한 텍스처를 가진다.
   국소 표준편차(local std) 맵에서 이 텍스처 경계가 뚜렷한 능선(ridge)으로 나타나므로,
   동적계획법(DP)으로 좌→우 전체 폭에 걸쳐 "누적 능선 강도가 최대가 되는 하나의
   연속 경로"를 추적한다 (지진파 층서 피킹과 동일한 기법). 매끄러움 패널티를 줘서
   더 강하지만 무관한 결정립계 고리로 튀는 것을 막았다. Cu는 이 데이터셋에서 항상
   프레임 하단부에 촬영되므로 탐색 범위를 하단 65% 영역으로 제한한다.

2. **Solder/IMC 경계 (불확실 단계 — 자동화하지 않고 표시만 함)**
   Cu 경계 위쪽 영역의 밝기 히스토그램이 **실제로 이봉분포(bimodal)일 때만** 경계를
   추적한다. 두 개의 뚜렷한 피크와 계곡이 없으면(= 이 프레임에 solder가 안 보이거나
   대비가 부족하면) 추측하지 않고 "frame_top_to_cu (lower bound)"로 보고하며
   신뢰도를 low로 표시한다. 즉 자신 없는 구간은 자동으로 밀어붙이지 않고 사람에게 넘긴다.

## 알려진 한계 (읽고 나서 결과 신뢰도 판단할 것)

- **Solder가 프레임에 안 보이는 이미지가 다수** (`IMC 측정` 폴더 72장 중 약 55장):
  이 경우 보고되는 두께는 "Cu 경계 ~ 프레임 상단" 거리이며 실제 IMC 두께의
  **하한값(lower bound)** 일 뿐이다. 그림 촬영 시 solder까지 포함해서 찍었는지
  확인 필요.
- **가파른/키가 큰 scallop 형상**에서는 DP가 드물게 연마 스크래치 선 같은 무관한
  능선으로 새는 사례를 확인함 (예: `100_200_9.jpg`). 이런 경우도 대개
  "low confidence"로 flag 되긴 하지만, **오버레이 이미지를 열어 노란선이 실제
  Cu/IMC 경계를 따라가는지 항상 눈으로 확인**해야 한다.
- Solder/IMC 경계(빨간선)는 Cu 경계보다 근본적으로 불확실한 단계이므로 confidence가
  "medium" 이상으로는 올라가지 않도록 설계했다 — 자동 검출이어도 사람 확인을 권장.
- 계면 근접 촬영이 아닌 이미지(저배율 볼 전체 사진, 평면(plan-view) 사진 등)에는
  적용되지 않으며 `status: not_applicable`로 표시된다.

## 스케일 보정

JEOL SEM이 내보낸 `.txt` 사이드카(같은 파일명)에서 `$$SM_MICRON_BAR`(스케일바 픽셀
길이)와 `$$SM_MICRON_MARKER`(실제 길이, 예: "10um")를 읽어 픽셀→μm를 계산한다.
이미지 옆에 `.txt`가 없으면(`IMC 측정` 폴더처럼 복사만 된 경우) `--meta-root`로 지정한
폴더 전체에서 같은 파일명의 `.txt`를 찾아 사용한다. 그래도 없으면 `--scale-um-per-px`로
수동 지정하거나, 결과에 `scale_source: None`으로 표시되어 후처리에서 걸러낼 수 있다.

## 사용법

```
cd C:\Users\82109\IMC_Thickness_Tool

# 이미지 1장
python -m imc_tool.cli single "경로\이미지.jpg" ^
    --meta-root "E:\00_정명진\03_연구실 컴퓨터\03_SBSAC_Reliability" ^
    --overlay "결과\확인용_오버레이.png"

# 폴더 전체 일괄 처리 (하위 폴더 포함)
python -m imc_tool.cli batch "이미지가_있는_폴더" ^
    --meta-root "E:\00_정명진\03_연구실 컴퓨터\03_SBSAC_Reliability" ^
    --out "결과.csv" ^
    --overlay-dir "오버레이_폴더"
```

`imc_results.csv`, `overlays/` 는 `IMC 측정` 폴더(72장)에 대해 이미 실행한 결과다.
CSV의 `needs_review` 열이 True인 행은 사람이 오버레이를 열어 확인해야 하는 항목이다.

## 다음 배치 실행 시

전체 SEM 원본 폴더(약 1,000장, `IMC 측정`이 아닌 각 날짜별 폴더)에도 그대로 돌릴 수
있다. `--meta-root`를 SBSAC_Reliability 루트로 주면 `.txt` 인덱스를 한 번만 만들어
전체를 훑으므로 매 이미지 개별 검색보다 빠르다.
